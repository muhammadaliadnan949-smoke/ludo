# Classic & Professional Ludo Web Application

A feature-rich, interactive web implementation of the classic board game **Ludo**.

## Features
- **Local Multi-player Support**: Play with 2 to 4 players (Red, Green, Yellow, Blue).
- **Sound Effects & Audio**: Built-in audio cues for dice rolls, token movements, captures, and victory.
- **Interactive UI**: Responsive board design, smooth animations, turn indicators, and real-time game logs.
- **Rules Implementation**: Standard Ludo rules including safe zones, double-six bonus turns, exact destination rolls, and token captures.

## How to Play
1. Open index.html in any modern browser.
2. Select player colors and start the game.
3. Roll the dice when it's your turn.
4. Move your tokens to reach the center home triangle.
